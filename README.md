# Veridian — Agent Operations Center

Hackathon demo: ambient agent swarm → zoom into a 5-agent cluster → scripted SynapseFlow scenario.

## Run

```bash
npm install
npm run dev
```

Open the local URL (Vite will print it). Demo path:

1. Cold open on the swarm (org-scale metrics)
2. Click **ENTER VANTIX AI**
3. Click **Deploy agents to investigate**
4. Watch SynapseFlow play through the SENTINEL block and trust reweights

## Stack

React + TypeScript + Vite, Tailwind, Pixi.js (swarm), React Flow (cluster), Zustand, Framer Motion
